# Coach AI

Your personal AI football coach. Upload a clip, get professional coaching feedback.

## Status

**Milestone 0 complete** — Clean Expo SDK 54 foundation.

## Quick Start

```bash
cd coach-ai
npm install
cp .env.example .env.local   # optional — add Supabase credentials when ready
npx expo start
```

Scan the QR code with **Expo Go SDK 54** on your device.

Without Supabase credentials, the app runs in dev mode (auth bypassed for navigation).
